# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting for
`edujbarrios/suffice`, not a public issue. Include affected versions, impact,
reproduction steps, and suggested mitigation. Maintainers will coordinate
disclosure after a fix; this volunteer project makes no response-time guarantee.

Suffice expects credentials only through environment variables. Artifacts
redact secret-shaped fields, but review them before publishing. Never place a
credential in YAML, tasks, prompts, metadata, or tool output.
